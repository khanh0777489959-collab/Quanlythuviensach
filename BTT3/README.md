# Quanlysachthuvien - Bài Thực Hành Tuần 3

Chương trình Quản lý sách thư viện - Tính giá trị nhập kho sách viết bằng ngôn ngữ Java.

## Yêu cầu thực hiện:
- **Bài 1:** Nhập mã sách, tên sách, tác giả, năm xuất bản, đơn giá, số lượng và hiển thị lại.
- **Bài 2:** Tính thành tiền = đơn giá × số lượng.
- **Bài 3:** Phí vận chuyển = 5% giá trị sách.
- **Bài 4:** Tổng tiền nhập = Thành tiền + Phí vận chuyển.
